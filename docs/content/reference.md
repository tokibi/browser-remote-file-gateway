# API and HTTP reference

## JavaScript API

Import `RemoteFileGateway` and `RemoteFileGatewayError` from the package root. Import `createRemoteFileGatewayHandler` from its `service-worker-handler` subpath in an existing module Service Worker.

```js
import {
  RemoteFileGateway,
  RemoteFileGatewayError,
} from 'browser-remote-file-gateway'

import {
  createRemoteFileGatewayHandler,
} from 'browser-remote-file-gateway/service-worker-handler'
```

| API | Description |
|---|---|
| `RemoteFileGateway.register(options)` | Register the standalone module Service Worker, wait until it controls the page, negotiate the protocol, and set the cache threshold. |
| `RemoteFileGateway.initialize(options)` | Alias for `register(options)`. |
| `RemoteFileGateway.connect({ registration, virtualBase, ... })` | Connect the page controller to an existing Service Worker registration. The host installs and routes the handler. |
| `gateway.registration` / `gateway.scope` | Read the associated registration and scope path. |
| `gateway.virtualUri(objectId)` | Return the absolute same-origin URL for a published object ID. |
| `gateway.publishBindings(revision, bindings)` | Atomically replace the full provider binding set. `revision` is a non-negative `bigint`. |
| `gateway.setCredential(provider, credential)` | Set a provider credential in Service Worker memory. Current supported authenticated provider: `google-drive`. |
| `gateway.clearCredential(provider)` | Clear a provider credential shared by clients using the registration. |
| `gateway.configureCache(maxFullObjectCacheBytes)` | Set the maximum size of an individual object eligible for OPFS caching. `0` disables caching. |
| `gateway.diagnostics()` / `gateway.resetDiagnostics()` | Read or reset the bounded in-memory diagnostic records. |
| `gateway.close()` | Release this controller instance and its `controllerchange` listener. |
| `createRemoteFileGatewayHandler({ virtualBase })` | Create the listener-free handler for a host module Service Worker. |

Controller methods reject with `RemoteFileGatewayError` when a control-plane operation fails. The error's `.code` is machine-readable. `close()` is idempotent.

### Binding fields

All bindings require `objectId`, `provider`, `bytes`, `contentVersion`, and optionally `mimeType` (default `application/octet-stream`). Object IDs match `[a-z0-9][a-z0-9-]{0,127}`; byte length must be a positive safe integer.

| Provider | Required provider fields | Immutable identity fields |
|---|---|---|
| `http-range` | `locator` — HTTP(S) URL | provider, bytes, `contentVersion` |
| `google-drive` | `fileId` — Drive ID | provider, bytes, MD5 `contentVersion`, `fileId` |

`apiBase` is optional for Google Drive and defaults to `https://www.googleapis.com/`. For Google Drive, `contentVersion` must be a 32-character lowercase hexadecimal MD5 checksum. `mimeType` affects the HTTP response header only.

`publishBindings()` replaces the entire active set. Revisions must increase, or repeat the current revision with identical binding content. The same object ID cannot later identify different immutable fields. HTTP `locator` and `mimeType` can change without changing identity.

### Credential shape

```js
{
  accessToken: '…',
  generation: 'token-refresh-18',
  expiresAt: Date.now() + 45 * 60 * 1000,
}
```

`accessToken` is 8–4096 characters; `generation` is a 1–64 character identifier using letters, digits, `_`, or `-`; `expiresAt` is a safe-integer epoch timestamp in milliseconds. Tokens remain in the Service Worker process memory. They are shared within that registration and should be cleared explicitly when the host application logs out.

## HTTP contract

Virtual URIs have this form, with no file suffix:

```text
<virtualBase>objects/<objectId>
```

The default `virtualBase` is `/remote-file-gateway/`.

| Request | Result |
|---|---|
| `HEAD` without `Range` | `200` with the full object length and byte-range headers. |
| `HEAD` with a valid single `Range` | `206` with selected range metadata and no response body. |
| `GET` with a valid single `Range` | `206` with the requested bytes. |
| `GET` without `Range` | `400` (`RC_RANGE_REQUIRED`). |
| Unsupported method | `405` (`RC_METHOD_NOT_ALLOWED`); `Allow: GET, HEAD`. |
| Invalid, suffix, or multiple range | `416` (`RC_RANGE_NOT_SATISFIABLE`) and `Content-Range: bytes */<size>`. |

Supported ranges use `bytes=<start>-<end>` or `bytes=<start>-` and are clamped to the end of the object. Suffix ranges and multiple ranges are not supported. A remote provider must support a bounded range response unless an eligible complete object is served from OPFS.

Every error response generated by the Gateway includes `X-Remote-File-Gateway-Error-Code`. Requests outside the configured virtual base and messages outside the `REMOTE_FILE_GATEWAY_` namespace are not claimed by the handler.

## Current error codes

Examples include `RC_AUTHENTICATION_REQUIRED`, `RC_AUTHORIZATION_DENIED`, `RC_OBJECT_NOT_FOUND`, `RC_CONTENT_REVISION_CHANGED`, `RC_RANGE_REQUIRED`, `RC_RANGE_NOT_SATISFIABLE`, `RC_RANGE_UNSUPPORTED`, `RC_CACHE_BODY_INVALID`, and `RC_REMOTE_FETCH_FAILED`. Use the response code header for HTTP requests and the `.code` property for controller errors; avoid branching on human-readable error messages.

## Runtime requirements and limits

- Service Workers run only in secure contexts (HTTPS or localhost).
- Provider requests are made from the Service Worker and remain subject to the provider's CORS and authorization rules.
- Google Drive credentials are held in RAM, while bindings persist in IndexedDB.
- OPFS is optional. The cache limit applies per object and does not bound aggregate storage use.
- The Gateway does not create Dedicated Workers, parse files, or guarantee a content hash for uncached provider range reads.
- The API is experimental and may evolve.
